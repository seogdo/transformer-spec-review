# 과제 조건과 제출 점검

> **최종 실행 기준:** OpenAI API의 `gpt-4o-mini`로 V01·V02·V03의 실제 요청과 결과를 확인했습니다. 새 실행 요약·캡처를 제출 자료에 사용하며, 기존 Ollama 시험과 F04 고정 응답 재생은 역사적 기록으로 보존합니다. [실행 출처와 제출 점검](ai-backends.md)을 확인하세요.

과제 2인 신규 프로젝트로 **변압기 수주 기술사양 검토 AI**를 개발했습니다. 수주 확정 후 기술 인계회의 전에 고객 요구와 내부 인계표의 차이를 확인하는 로컬 프로토타입입니다.

기준은 제공된 「AI 서비스 Mini Project_20261020」의 PDF 3쪽, 10~13쪽과 이후 전달된 보고서·5분 발표 공지입니다. 보고서 구성과 발표 시간은 최신 공지를 우선합니다. 교재 원본은 공개 저장소에 포함하지 않았습니다. 아래 상태는 구현·자료 준비 여부이며 예상 점수나 제출 완료를 의미하지 않습니다.

## 평가 항목 구분

기능 완성도 30점, 기술 요소 30점, 한계·트레이드오프 20점, 발표자료와 발표 20점입니다. 동일 입력의 Before/After 수치 비교는 **10점 보너스**입니다. 배점은 교재 기준이며 채점 결과를 보장하지 않습니다.

교재의 Multi-Agent, MCP, RAG, 의존성 주입, LangSmith, 모듈화, 단위 테스트는 기술 선택과 설명의 기준으로 검토했습니다. 새 발표 공지에 Agent Graph·MCP·RAG 코드 설명이 언급됐다는 이유만으로 모든 기술의 구현을 필수라고 단정하지 않습니다. 현재 구현한 코드로 실행 구조와 기술 선택을 설명하며, 필요 시 교수자에게 적용 범위를 확인합니다.

이 프로젝트의 실행 흐름은 `extract_upload`의 **Python 제어 흐름**입니다. 키워드 기반 RAG·구조화 출력 검증·의존성 주입·모듈화·테스트를 사용했습니다. **Multi-Agent·MCP·LangGraph·LangSmith·임베딩 벡터 검색은 사용하지 않았습니다.** 흐름도는 코드 실행 순서의 설명이며 LangGraph `StateGraph`나 MCP 서버·클라이언트를 구현한 증거가 아닙니다. 코드 설명에서는 미사용을 명시하고, 실제 검색 함수와 다음 모델 요청으로 근거를 전달하는 경로를 보여줍니다.

기본 프로젝트 실행·모델 초기화 절차는 과제 1의 제공 프로그램 안내입니다. 과제 2의 기능 확인을 위해 기존 모델을 삭제하거나 기본 프로젝트를 재구축할 필요는 없습니다.

## 전후 비교의 범위

F04 가상 문서와 당시 Ollama 응답을 고정하여 근거 표시 개선을 점검합니다. 이전 저장 결과와 현재 코드 재생 결과의 출처 차이를 공개하고, 충돌 근거 표시 수와 판정·값 보존 여부를 비교합니다. 실제 AI를 새로 실행한 정확도·속도 비교도, OpenAI 전환 성능 비교도 아닙니다.

[측정 결과](../reports/evidence-before-after-20261020T111053Z-4e8705ae.json)에서 충돌 근거 표시가 1개에서 2개로 보완되고 10항목의 판정·정규화값이 유지됐습니다. 이 측정 보완 당시에는 Python 검사 376개와 화면 모의 검사 58개가 통과했습니다. 10월 21일 미확정값·변경서 선택 복원 보완 후에는 Python 385개와 화면 모의 검사 65개가 통과했습니다. 두 검사 수치 모두 AI 정확도 측정값은 아닙니다.

현재 자동검사는 Python **444개**, DOM **71개**입니다. 별도로 OpenAI 실제 V01~V03의 30항목 기대 상태 일치를 확인했지만, 이는 소량 합성 수용시험으로 독립 정확도나 현업 성능으로 일반화하지 않습니다. V02는 API 요청 2/2가 완료돼도 추출은 20/21로 partial이며 주파수는 보류입니다.

교재는 같은 입력으로 개선 전후를 실행한 수치 비교를 요구합니다. 과거 코드의 신규 재실행을 포함하지 않는 저장 결과 비교는 그보다 제한된 증거이므로, 보너스 충족을 확정하지 않습니다. 측정 방법과 한계를 함께 제출합니다.

## 제출 전 최종 확인

- [OpenAI 실제 실행 요약](../reports/openai-validation-20261021.json)의 `gpt-4o-mini`, 사례별 요청·추출·판정 결과를 최종 PDF·PPT·대본과 대조합니다. 기존 Ollama 캡처를 OpenAI 결과로 이름만 바꾸지 않습니다.
- 제출용 보고서 첫 페이지의 **G077 문성도**와 과제 2의 주제·주요 task를 확인합니다.
- 사용 기술, 기능 화면·최종 실행 캡처, 느낀 점·향후 개선이 최종 PDF·PPT에 포함됐는지 확인합니다. 선택 전후 비교는 수치·캡처·측정 한계를 함께 대조합니다.
- 본인 반 시트에서 UID·이름·선택 과제 2·주요 기능을 확인합니다. 사용자는 **2026년 10월 22일에 시트 입력을 직접 진행할 예정**이며, 아직 입력 완료로 표시하지 않습니다.
- Git 주소와 제출용 최종 보고서 주소를 각각 입력합니다. 보고서는 로그인하지 않은 창에서도 열리는지 확인합니다. V03의 회의용 9쪽 PDF와 제출용 최종 보고서를 혼동하지 않습니다.
- 주소 등록 마감과 발표 시간은 반별 최신 공지를 확인합니다. 발표 분량은 **총 5분, 1~4장 결과 설명 2분과 5~9장 코드 설명 3분**입니다. 역할·보고서·상세 검증·전후 비교 등을 담은 부록 9장은 질문이 있을 때만 엽니다.
- 저장된 실제 실행 캡처를 주 자료로 준비합니다. 추가 실시간 추출은 발표 전에 연결·소요시간을 확인한 경우에만 선택적으로 진행하며 5분 본 발표의 필수 단계로 두지 않습니다.
- [5분 대본](presentation-demo.md)의 실행 흐름·검색·검증·비교·의존성 주입을 본인 말로 설명합니다. 자료 작성이 코드 이해나 발표 수행을 대신하지는 않습니다.

원문 PDF 뷰어 다운로드 버튼 완료 확인, 실제 회사 문서 정확도, 업무시간 절감률은 확인한 결과로 표시하지 않습니다.
