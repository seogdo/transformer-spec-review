# AI 실행 방식과 최종 제출 전환

## 강의 ZIP에서 확인한 내용

`all_total_vue_student.zip`의 `doc/README.md`, `doc/manual_openai.md`, `agent/openai_llm.py`, `web_chat.html`을 확인했습니다.

- 원본은 `LLM_BACKEND`로 `fake`, `ollama`, `openai`를 서버 시작 시 선택합니다.
- `openai`는 일반적인 공개 웹 API가 아니라 **OpenAI의 실제 유료 AI API**입니다.
- 같은 웹 화면이 `/health`를 조회해 현재 제공업체·모델을 표시합니다. Ollama/API용 HTML을 따로 복제하는 방식이 아닙니다.
- 강의 예제의 모델 분리, LangSmith, MCP, LangGraph는 원본의 구성입니다. 이를 확인했다는 이유로 우리 앱에 구현했다고 주장하지 않습니다.

우리 앱은 기존 로컬 Ollama와 OpenAI API의 두 실행 방식을 지원하며, 비교 엔진·검색·출처 검증은 공통으로 사용합니다. 강의 원본 파일이나 실제 키를 저장소에 복사하지 않습니다.

## 실행 선택

```sh
# 최종 제출 검증
.venv-app/bin/python scripts/run_web.py --backend openai

# 로컬 테스트
.venv-app/bin/python scripts/run_web.py --backend ollama
```

기본 주소는 `http://127.0.0.1:8765`입니다. 서버가 이미 실행 중이면 그 서버의 터미널에서 Ctrl+C로 종료한 뒤 선택한 방식으로 다시 실행합니다. 기존 작업·저장 기록은 삭제하지 않습니다. 별도 검사 환경에는 `--port 8766`처럼 다른 포트를 사용할 수 있습니다.

`.env.example`을 `.env`로 복사하고 서버 전용 설정을 작성합니다. `OPENAI_API_KEY`는 본인 키, `OPENAI_MODEL`은 본인 계정에서 접근 가능한 Chat Completions/Structured Outputs 지원 모델입니다. 모델 자동 선택이나 API 키 자동 발급은 하지 않습니다. 키를 명령줄 인자·브라우저·공유 문서·채팅으로 전달하지 마세요.

`--backend` > 서버의 `LLM_BACKEND` > `.env`의 `LLM_BACKEND` > 실행 도구 기본값 `openai` 순서로 선택합니다. 다른 환경값도 기존 서버 환경변수가 `.env`보다 우선합니다. 라이브러리 직접 호출은 이전 로컬 검사와의 호환을 위해 기본 `ollama`입니다.

## 화면에서 구분하는 것

| 구분 | 의미 |
| --- | --- |
| 서버 실행 방식 | 앞으로 버튼으로 요청할 AI의 제공업체·모델입니다. |
| 설정 상태 | 키·모델 설정 여부이며, 실제 모델 접속·잔액·권한 검증은 아닙니다. |
| 저장된 실행 출처 | 해당 결과를 만들 때의 제공업체·모델입니다. 현재 서버 설정으로 덮어쓰지 않습니다. |
| 주입 응답 검사 | 고정 응답으로 코드만 검사한 실행입니다. 실모델 성능·과금 결과가 아닙니다. |

OpenAI 모드의 추출과 선택 설명은 외부 처리·과금 동의를 직접 확인해야 시작합니다. 동의는 페이지 복원 시 자동으로 체크하지 않습니다. 키가 없거나 API가 실패하면 사유를 보여주고 미확정 값을 유지합니다. Ollama나 다른 모델로 자동 전환하지 않습니다.

## 외부로 보내는 범위

- 추출 1차: 문서 식별자, 대상 항목, 검색어 별칭입니다.
- 추출 2차: 검색 도구가 찾은 원문 구간과 문서·페이지 정보입니다.
- 선택 설명: 코드가 결정한 비교값·상태·이유 식별자·출처 정보입니다.
- API 키는 서버의 인증 헤더에만 사용합니다. 화면·저장 결과·보고서에 포함하지 않습니다.

가상 자료만 사용하며 실제 회사 문서·고객 기밀·개인정보는 업로드하지 않습니다. `store:false`를 보내지만 이것만으로 제공업체의 모든 데이터 보관이 없다는 뜻은 아닙니다. 정책에 따른 외부 처리가 존재합니다. 정형 PDF 처리·과거 기록 조회·회의 보고서 인쇄는 AI를 다시 호출하지 않습니다.

## 최종 제출 전에 남은 검증

1. 본인 OpenAI 키·사용 가능 모델을 서버에 설정합니다.
2. API 모드에서 V01 예시를 읽고 동의 후 추출을 실행합니다.
3. 성공 여부, 실제 제공업체·모델, 출처·검증 결과를 새 실행 기록으로 확인합니다. 기존 Ollama와 같은 수치가 나올 것이라고 미리 가정하지 않습니다.
4. 새 API 화면을 캡처하고 최종 PDF·PPT와 발표 대본의 실행 결과를 갱신합니다.
5. 발표용 5분 구성(주제·결과 2분 / 코드 3분)은 유지합니다. 최종 링크의 접근성을 확인한 뒤 제출 시트에 입력합니다.

현재 기존 PDF·PPT의 V01~V03 캡처와 수치는 **Ollama 실행 결과**입니다. API 실호출 검증이 끝나기 전에는 OpenAI 최종 완료로 소개하지 않습니다. 자동 검사의 통과는 실제 API 호출 성공이나 모델 정확도 측정을 의미하지 않습니다.
