# 결선그룹과 냉각방식 불일치 사례 시연

2026년 10월 22일 기존 서비스와 OpenAI API의 `gpt-4o-mini`로 새 가상 문서 세트를 실행했습니다. 승인 변경서의 결선그룹·냉각방식이 내부 인계표에 반영되지 않은 사례입니다. 핵심 코드는 변경하지 않았으며 기존 V01~V03 문서와 실행 기록도 그대로 보존했습니다.

## 확인된 결과

| 항목 | 승인 변경서 AMD-R04 1쪽 | 내부 인계표 HANDOFF-R04 2쪽 | 결과 |
| --- | --- | --- | --- |
| 결선그룹 | Dyn11 | Dyn1 | 불일치 |
| 냉각방식 | OFAF | ONAF | 불일치 |
| 팬 보조전원 | 기존 고객사양 유지 | 380 V | 일치 |

원본 고객사양과 인계표의 팬 보조전원은 모두 380 V입니다. 최종 비교는 **8개 일치·2개 불일치·누락 0개·확인 필요 0개**였습니다. API 요청은 2회 모두 완료됐고 제안값 22개가 원문 검증을 통과했습니다. 개발자가 작성한 합성 문서의 수용시험 결과이며 독립적인 AI 정확도 평가가 아닙니다. 13.176초는 이 실행에서 관측한 단일 소요시간으로, 성능 개선이나 처리시간 보장을 뜻하지 않습니다.

[공개 실행 요약](../reports/openai-r04-validation-20261022.json)에서 값과 근거 페이지, 입력 PDF 해시를 확인할 수 있습니다.

## 입력 파일

- 고객 사양서: [01_customer_spec.pdf](../output/pdf/revised/R04/01_customer_spec.pdf)
- 변경 합의서: [02_amendment.pdf](../output/pdf/revised/R04/02_amendment.pdf)
- 내부 인계표: [03_handoff.pdf](../output/pdf/revised/R04/03_handoff.pdf)

이 문서는 실습용 가상 자료입니다. 실제 고객의 주문이나 설계 기준이 아닙니다. 결선그룹·냉각방식의 차이를 비교하지만 설계 적합성, 병렬운전 가능 여부, 냉각 성능이나 허용 용량을 승인하지 않습니다.

## 페이지에서 실행하는 순서

1. [OpenAI 실행 안내](ai-backends.md)에 따라 서버를 켜고 페이지 상단의 실행 방식과 모델을 확인합니다. 기존 서버가 다른 포트를 사용 중이면 그 서버 주소로 접속합니다.
2. 문서 처리 방식을 **AI 근거 추출용 텍스트 PDF**로 선택합니다. 위 파일 3개를 각각 고객 기술사양서·기술 변경 합의서·내부 수주 인계표 위치에 직접 선택하고 **문서 읽기**를 누릅니다. **V01 예시 버튼은 기존 팬 전원 사례이므로 R04 시연에 사용하지 않습니다.**
3. 고객사 확인 결과와 문서 ID `SPEC-R04`, `AMD-R04`, `HANDOFF-R04`를 확인합니다. OpenAI 외부 전송·과금에 동의한 뒤 **AI로 근거 찾고 항목 추출**을 한 번 누릅니다.
4. 추출 완료 후 승인 변경 `AMD-R04`의 적용 관계를 확인하고 기준 확인란을 체크합니다. **10개 항목 검토하기**를 누릅니다.
5. 결선그룹과 냉각방식 행을 선택해 양쪽 문서의 값과 페이지를 확인합니다. 사람이 원문을 검토한 후 확인란을 체크하고 **회의용 보고서 열기**를 누릅니다.

재실행 결과가 다르면 실제 표시를 그대로 확인합니다. 8일치·2불일치를 맞추기 위해 값을 수정하지 않습니다. 검색·추출 실패나 불명확한 값은 보류하고 원문을 다시 확인합니다. 저장한 보고서와 화면 캡처를 보여줄 때는 사전 실행 기록이라고 설명합니다.
