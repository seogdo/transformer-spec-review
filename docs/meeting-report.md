# 회의용 검토 보고서

사람이 결과와 원문을 확인한 후 저장 기록을 회의 자료로 열 수 있습니다. 보고서는 새로운 검토나 승인 기록이 아니며, 저장된 값·판정·사유·원문 근거를 표시합니다.

## 사용하는 순서

1. 문서를 읽고 적용할 변경 기준을 확인한 다음 검토를 실행합니다.
2. 확인이 필요한 항목의 양쪽 원문을 대조합니다.
3. 결과 아래의 **표시된 결과와 원문을 사람이 검토했습니다**를 체크합니다.
4. **회의용 보고서 열기**를 선택합니다.
5. **인쇄 · PDF로 저장**을 누릅니다. PDF 저장은 브라우저에서 제공하는 인쇄 기능을 사용합니다.

인쇄 창을 취소해도 앱은 저장 완료로 표시하지 않습니다. 파일 저장 여부와 경로는 브라우저에서 직접 확인합니다.

## 보존하는 정보

- 저장된 항목 수와 판정, 요구값·인계값·단위, 판정 사유입니다.
- 고객사 기본정보, 문서 목록과 적용한 변경 기준입니다.
- 문서 ID·페이지·인용문과 저장된 근거 대조 정보입니다.
- 확인 필요 상태, 빈값과 누락 메타데이터입니다. 과거 8항목 기록을 현재 10항목 결과로 바꾸지 않습니다.

원문 후보는 채택된 값과 구분합니다. 메타데이터가 없는 과거 기록은 현재 방식으로 검증됐다고 표시하지 않습니다.

## 확인한 범위

V03 가상 문서를 실제 로컬 AI와 화면에서 검토한 결과는 8개 일치·2개 불일치였습니다. 차이는 OLTC 요구/DETC 인계, 옥외형 요구/옥내형 인계입니다. 이 저장 기록을 Chrome 인쇄 기능으로 실제 PDF에 저장했으며, 생성된 **9쪽 전체 페이지의 시각 검사**를 통과했습니다.

저장한 PDF의 텍스트에는 결과 10행에 속한 원문 인용 20개가 모두 있었고, null 저장값 표시도 확인했습니다. 보고서 조회·인쇄 전후 저장 파일 22개의 해시를 비교한 결과 변경은 없었습니다.

회의용 보고서 기능 확인 당시 Python 자동검사 362개와 DOM·fetch 모의 검사 58개(근거 12개·복구 32개·보고서 14개)가 통과했습니다. 이후 전후 측정 검사까지 추가한 전체 Python 검사는 376개입니다. 과거 8항목 기록의 보존과 예외 처리는 자동검사로 확인했으며, 실제 브라우저에서 과거 기록을 시연했다고 주장하지 않습니다.

이 결과는 직접 만든 가상 개발 자료에 대한 확인입니다. 다른 브라우저의 인쇄·저장, 원문 PDF 뷰어 다운로드 버튼의 완료 여부, 모든 시간 초과·다중 탭 조합은 검증 범위에 포함하지 않습니다.

## 처리와 제한

보고서 조회는 저장 JSON을 읽는 GET 요청입니다. AI 호출, 비교 재실행, 새 요약 생성, 기존 기록 수정은 하지 않습니다. 서버가 PDF를 생성하거나 업로드하지 않으며 자동 메일·결재 기능도 없습니다.

문서 내용은 HTML로 실행하지 않고 문자로 표시합니다. 원본 PDF 링크는 검증된 업로드 ID·문서 ID·페이지로만 구성하며 저장 데이터에 포함된 임의 주소는 사용하지 않습니다.

보고서의 승인 표기는 가상 입력 메타데이터입니다. 실제 승인 권한·문서 진위·설계 적합성·제품 안전을 보증하지 않습니다.

이 회의용 보고서는 개별 검토 기록의 출력입니다. 저장 후 8쪽 전체의 시각 검사를 마친 제출용 [프로젝트 최종 보고서](../output/pdf/final-report.pdf)와 별도이며, 가상 시험 결과를 실제 회사 문서 정확도나 시간 절감률로 해석하지 않습니다.
