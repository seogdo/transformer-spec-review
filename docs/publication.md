# 공개 사본과 검증 범위

이 저장소는 변압기 수주 기술사양 검토 프로토타입의 제출용 사본입니다. 앱 소스와 가상 시연·검증 자료를 포함하며, 개발용 원본 폴더와 개인 작업 기록은 별도로 보존했습니다.

## 포함한 자료

- 웹 앱 소스, 자동 검사, 실행·가상 샘플 생성 도구입니다.
- 모든 PDF는 직접 구성한 가상 자료입니다. 고객사 이름은 비교 기능을 보여 주는 지정 후보이며 실제 거래 문서가 아닙니다.
- 화면 이미지는 가상 PDF를 사용한 로컬 시험 결과입니다.
- `reports/fresh-evaluation-20261020T134647-008a1935.result.json`은 근거 연결 회귀 검사에서 모델 응답을 재생하기 위한 자료입니다. 개인 절대경로를 제거한 공개용 사본이며, 변경되지 않은 동결 원본과 바이트가 같다고 주장하지 않습니다. 값·판정·모델 응답을 실제 AI의 새 실행 결과로 바꾸지 않았습니다.
- `reports/evidence-before-after-20261020T111053Z-4e8705ae.json`은 F04의 이전 저장 결과와 현재 코드의 고정 응답 재생 비교입니다. 원본 PDF 해시 일치, 충돌 근거 표시, 판정·정규화값 보존을 기록했습니다. 개인 절대경로를 포함하지 않습니다.

## 제외한 자료

강의용 원본 코드, 가상환경, 모델 가중치, API 키·환경설정, 개인 업로드 저장소, 다운로드 파일, 임시 실행 폴더, 일반 실행 로그, 과거 소스 압축파일은 제외했습니다. 모델과 강의 원본은 앱 실행 시 자동 다운로드하지 않습니다.

일부 개발 도구는 새 실행 시 로컬 `reports/`나 `tmp/`에 결과를 만듭니다. 재공개 전에는 개인 경로와 민감정보를 확인해야 합니다. 기존 개발 환경의 실행 ID와 저장 자료가 필요한 과거 검증 전용 스크립트는 포함하지 않았습니다.

## 검사 결과 해석

자동 회귀 검사는 코드의 처리 규칙과 모의 응답 처리를 검사합니다. 실제 모델의 추출 정확도를 측정하는 시험이 아닙니다.

2026년 10월 20일 전후 측정 검사 보완 후 공개용 로컬 폴더에서 기존 개발 가상환경을 사용해 Python 자동 검사 **376개**가 **13.107초**에 통과했습니다. DOM·fetch 모의 검사는 근거 **12개**, 복구 **32개**, 보고서 **14개**, 합계 **58개**가 모두 통과했습니다. 검사 실행시간은 앱 처리속도 측정값이 아니며, 새 컴퓨터의 의존성 설치까지 검증한 결과도 아닙니다.

2026년 10월 21일 최종 반영 전 같은 공개용 폴더에서 Python 376개와 DOM·fetch 모의 검사 58개를 다시 실행해 모두 통과했습니다. 이 재검증에서 실제 모델이나 외부 서비스는 호출하지 않았습니다.

실제 로컬 AI와 화면에서 확인한 가상 사례는 다음과 같습니다.

- **V01:** 21개 추출값이 원문 대조를 통과했고, 기술 항목은 9개 일치·1개 불일치였습니다. 원문 PDF 표시, JSON 내려받기와 복원도 확인했습니다.
- **V02:** 9개 일치·1개 확인 필요였습니다. 주파수 미기재 항목은 확정하지 않고 보류했습니다.
- **V03:** 8개 일치·2개 불일치였습니다. OLTC 요구와 DETC 인계, 옥외형 요구와 옥내형 인계의 차이를 확인했습니다.
- **회의용 보고서:** V03 저장 기록을 Chrome에서 실제 PDF로 저장했으며, 생성된 9쪽 전체의 시각 검사를 통과했습니다. PDF 텍스트에서 결과 10행의 원문 인용 20개와 null 저장값 표시를 확인했고, 보고서 조회·인쇄 전후 저장 파일 22개의 해시 변경은 없었습니다.

파일 오류·AI 연결 실패·접수 후 응답 오류의 [재시도 흐름](error-recovery.md)도 확인했습니다. 과거 8항목 기록의 보존은 자동검사로 확인한 범위이며 실제 브라우저 시연으로 주장하지 않습니다. PDF 뷰어 다운로드 버튼의 완료 확인과 모든 시간 초과·다중 탭 조합의 실제 화면 시험은 여전히 별도 확인 대상입니다.

모든 결과는 직접 구성한 가상 개발 사례의 동작 확인이며 독립 평가가 아닙니다. 실제 회사 문서 정확도, 공학적 적합성 또는 업무 시간 절감률로 일반화하지 않습니다.
