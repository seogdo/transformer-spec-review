# 공개 사본과 검증 범위

> **현재 제출 기준:** 대표 발표 사례는 2026년 10월 22일 OpenAI API `gpt-4o-mini`로 실행한 R04입니다. 결선그룹·냉각방식 불일치를 확인했습니다. 10월 21일 V01·V02·V03과 과거 Ollama·고정 응답 재생은 별도 이력입니다. 자동검사, API 응답 완료, 원문 검증 통과, 최종 비교는 서로 다른 확인 항목입니다.

이 저장소는 변압기 수주 기술사양 검토 프로토타입의 제출용 사본입니다. 앱 소스와 가상 시연·검증 자료를 포함하며, 개발용 원본 폴더와 개인 작업 기록은 별도로 보존했습니다.

## 포함한 자료

- 웹 앱 소스, 자동 검사, 실행·가상 샘플 생성 도구입니다.
- 모든 PDF는 직접 구성한 가상 자료입니다. 고객사 이름은 비교 기능을 보여 주는 지정 후보이며 실제 거래 문서가 아닙니다.
- 화면 이미지는 가상 PDF를 사용한 시험 결과입니다. `output/openai-v01-result.png`부터 `openai-v03-result.png`까지는 새 OpenAI 저장 결과보고서의 상단 캡처(523×747)이며 메인 검토 화면이나 전체 결과표가 아닙니다. 기존 `live-browser-*` 화면은 Ollama 기록입니다.
- [OpenAI 실행 요약](../reports/openai-validation-20261021.json)은 V01~V03의 실제 제공업체·모델·요청 완료·추출·판정 결과를 구분한 공개 기록입니다.
- `reports/fresh-evaluation-20261020T134647-008a1935.result.json`은 과거 Ollama F01~F06의 기록이자 근거 연결 회귀 검사에서 모델 응답을 재생하기 위한 자료입니다. 개인 절대경로를 제거한 공개용 사본이며, 변경되지 않은 동결 원본과 바이트가 같다고 주장하지 않습니다. 값·판정·모델 응답을 OpenAI나 실제 AI의 새 실행 결과로 바꾸지 않았습니다.
- `reports/evidence-before-after-20261020T111053Z-4e8705ae.json`은 F04의 과거 Ollama 저장 결과와 고정 응답을 사용한 현재 코드 재생 비교입니다. 원본 PDF 해시 일치, 충돌 근거 표시, 판정·정규화값 보존을 기록했습니다. 실제 모델 호출은 0회이며 OpenAI 시험이 아닙니다. 개인 절대경로를 포함하지 않습니다.

## 제외한 자료

강의용 원본 코드, 가상환경, 모델 가중치, API 키·환경설정, 개인 업로드 저장소, 다운로드 파일, 임시 실행 폴더, 일반 실행 로그, 과거 소스 압축파일은 제외했습니다. 모델과 강의 원본은 앱 실행 시 자동 다운로드하지 않습니다.

일부 개발 도구는 새 실행 시 로컬 `reports/`나 `tmp/`에 결과를 만듭니다. 재공개 전에는 개인 경로와 민감정보를 확인해야 합니다. 기존 개발 환경의 실행 ID와 저장 자료가 필요한 과거 검증 전용 스크립트는 포함하지 않았습니다.

## 검사 결과 해석

자동 회귀 검사는 코드의 처리 규칙과 모의 응답 처리를 검사합니다. 실제 모델의 추출 정확도를 측정하는 시험이 아닙니다.

현재 OpenAI/Ollama 연결을 반영한 Python 자동검사 **444개**, DOM·fetch 모의 검사 **71개**(근거 12·복구 45·보고서 14)가 통과했습니다. 실제 API 요청 없이 키 누락·외부 전송 동의·설정 변경·응답 검증·보류·복원을 검사한 결과입니다. 아래 이전 검사 기록과 구분합니다.

2026년 10월 20일 전후 측정 검사 보완 후 공개용 로컬 폴더에서 기존 개발 가상환경을 사용해 Python 자동 검사 **376개**가 **13.107초**에 통과했습니다. DOM·fetch 모의 검사는 근거 **12개**, 복구 **32개**, 보고서 **14개**, 합계 **58개**가 모두 통과했습니다. 검사 실행시간은 앱 처리속도 측정값이 아니며, 새 컴퓨터의 의존성 설치까지 검증한 결과도 아닙니다.

2026년 10월 21일 최종 반영 전 같은 공개용 폴더에서 Python 376개와 DOM·fetch 모의 검사 58개를 다시 실행해 모두 통과했습니다. 이 재검증에서 실제 모델이나 외부 서비스는 호출하지 않았습니다.

같은 날 추가 검토에서 미확정·잠정·부정 표현의 보류 처리와 저장된 변경서 선택 복원을 수정했습니다. 숫자값의 명확한 ‘협의 완료’까지 보류하지 않는지도 검사했습니다. Python 검사 **385개**가 **13.289초**에 통과했고, DOM·fetch 모의 검사 **65개**(근거 12·복구 39·보고서 14)가 통과했습니다. 이 수치는 후속 수정본의 자동검사 결과이며 실제 모델을 새로 실행한 결과가 아닙니다. 과거 실제 AI 시험 결과는 아래에 구분해 보존했습니다.

### 10월 22일 대표 사례 R04

[R04 공개 요약](../reports/openai-r04-validation-20261022.json)은 실제 OpenAI 요청 2회 완료, 제안 22개 원문 검증 통과, 최종 8개 일치·2개 불일치를 기록합니다. AMD-R04 1쪽의 Dyn11/OFAF와 HANDOFF-R04 2쪽의 Dyn1/ONAF가 다르며 팬 보조전원 380 V는 일치합니다. [새 PDF 3종](r04-demo-case.md)은 별도로 업로드하며 기존 V01–V03 버튼과 핵심 소스는 변경하지 않았습니다.

`output/openai-r04-result.png`는 저장 보고서 상단, `openai-r04-rows.png`는 결과표 일부, `openai-r04-vector-evidence.png`와 `openai-r04-cooling-evidence.png`는 각각 양쪽 원문 캡처입니다. 개발자가 기대값을 구성한 가상 사례이며 독립 성능 평가가 아닙니다. 새 API 실행기록을 예전 수치나 제공업체 이름만 바꿔 만들지 않았습니다.

### 10월 21일 실제 OpenAI API 결과

사용자 동의 후 `openai / gpt-4o-mini`로 실행했습니다. 요청 완료 수는 완료된 구조화 응답을 받은 횟수이며 채택값 수나 정확도와 다릅니다.

| 사례 | API 완료 / 시도 | 원문 검증 통과 / 대상 | 최종 비교 |
| --- | --- | --- | --- |
| V01 | 2 / 2 | 21 / 21 · completed | 9 MATCH · 1 MISMATCH — 팬 440 V 요구 / 380 V 인계 |
| V02 | 2 / 2 | 20 / 21 · partial | 9 MATCH · 1 NEEDS_REVIEW — 주파수 미기재 |
| V03 | 2 / 2 | 22 / 22 · completed | 8 MATCH · 2 MISMATCH — OLTC / DETC, 옥외형 / 옥내형 |

위 V01–V03의 실제 요청은 총 6회 모두 완료됐습니다. 세 사례의 30항목 기대 상태 일치는 소량 합성 수용시험이며 독립 정확도 평가가 아닙니다. 최종 판정은 코드가 수행했고, V02 주파수의 `actual=null`, `evidence_complete=false`를 유지했습니다. 원문 연결 60개를 확인했지만 완전한 근거로 표시된 행은 29/30으로, 인용문의 페이지 연결과 검토 완전성은 구분합니다. 실제 청구 금액·추가 설명 API·시간 절감률은 이 결과로 검증하지 않습니다.

### 보존한 과거 Ollama 결과

전환 전 실제 Ollama와 화면에서 확인한 가상 사례입니다. 새 OpenAI 결과나 OpenAI 결과의 인쇄 시험으로 재표기하지 않습니다.

- **V01:** 21개 추출값이 원문 대조를 통과했고, 기술 항목은 9개 일치·1개 불일치였습니다. 원문 PDF 표시, JSON 내려받기와 복원도 확인했습니다.
- **V02:** 9개 일치·1개 확인 필요였습니다. 주파수 미기재 항목은 확정하지 않고 보류했습니다.
- **V03:** 8개 일치·2개 불일치였습니다. OLTC 요구와 DETC 인계, 옥외형 요구와 옥내형 인계의 차이를 확인했습니다.
- **회의용 보고서:** V03 저장 기록을 Chrome에서 실제 PDF로 저장했으며, 생성된 9쪽 전체의 시각 검사를 통과했습니다. PDF 텍스트에서 결과 10행의 원문 인용 20개와 null 저장값 표시를 확인했고, 보고서 조회·인쇄 전후 저장 파일 22개의 해시 변경은 없었습니다.

파일 오류·AI 연결 실패·접수 후 응답 오류의 [재시도 흐름](error-recovery.md)도 확인했습니다. 과거 8항목 기록의 보존은 자동검사로 확인한 범위이며 실제 브라우저 시연으로 주장하지 않습니다. PDF 뷰어 다운로드 버튼의 완료 확인과 모든 시간 초과·다중 탭 조합의 실제 화면 시험은 여전히 별도 확인 대상입니다.

모든 결과는 직접 구성한 가상 개발 사례의 동작 확인이며 독립 평가가 아닙니다. 실제 회사 문서 정확도, 공학적 적합성 또는 업무 시간 절감률로 일반화하지 않습니다.
