# 정형 PDF 가상 예시

모두 교육용으로 만든 가상 문서이며 회사 내부 자료나 실제 승인 문서가 아닙니다. 한 번에 같은 폴더의 사양서·합의서·인계표 3개만 사용합니다.

- D01: 냉각팬 전원이 승인 변경 440 V로 바뀌었으나 인계표에는 380 V가 남은 사례입니다.
- D02: 변경사항과 단위 표현이 정상적으로 반영된 사례입니다.
- C01: 서로 다른 고객사 문서가 섞여 기술 10개 항목 모두 판정을 보류하는 사례입니다.

[프로젝트 안내](../../../README.md)에 따라 로컬 앱을 실행한 후 예시 버튼을 누르거나, `기존 정형 PDF` 모드에서 `01_customer_spec.pdf`, `02_amendment.pdf`, `03_handoff.pdf`를 각각 선택합니다. 문서의 고객사와 승인 변경 적용 기준을 사람이 확인한 다음, 결과·인용문·원본 PDF를 대조합니다. JSON 내보내기는 사람의 검토 확인 후 가능합니다.

이 폴더는 고정 양식 파서를 사용합니다. 별도 [텍스트 PDF 예시](../varied/) V01~V03은 텍스트 읽기와 선택적 로컬 AI 근거 추출을 분리하고, 키워드·별칭 검색과 2회 모델 호출로 항목을 추출합니다. 추출값은 승인을 뜻하지 않으며 최종 비교·보류 판정과 설명 서식은 코드가 만듭니다. 고객사 누락·미등록·상충 시 AI 추출 없이 확인 필요 결과를 볼 수 있습니다.

지원 범위는 명시적 가상 문서, 한 프로젝트·한 제품·세 문서, 기술 10개 항목과 별도의 고객사 메타데이터입니다. 파일당 5 MiB·20페이지·추출 텍스트 20만 자 제한이 있으며, 스캔 PDF의 OCR·범용 회사 문서·벡터 RAG·MCP·모델 API의 native tool calling은 지원하지 않습니다. 실제 고객 관계나 설계 적합성도 검증하지 않습니다.

수동 정답은 평가용 파일에 별도로 보관되며 모델 입력에 넣지 않습니다. 이 예시들은 개발·회귀검증용 자료로, 독립된 성능평가 데이터가 아닙니다.
