01 / PREPARE

검토할 문서 3종을 준비하세요

PDF

현재 지원하는 가상 문서 템플릿을 사용합니다. 파일당 최대 5 MiB · 20쪽이며, 스캔 PDF와 OCR은 지원하지 않습니다.

먼저 문서 3종의 고객사 표기를 확인한 뒤, 탭절환기 방식(OLTC / DETC)과 설치 구분(옥내형 / 옥외형)을 포함한 기술사양 10개 항목을 비교합니다. 고객사 확인은 별도 기본정보이며 재질은 검토 범위에 포함하지 않습니다.

제공된 정형 PDF의 항목을 읽어 바로 승인 적용을 확인합니다.

지원하는 가상 텍스트 문서만 사용하세요

가상 자료 선언과 상단 메타데이터 3줄(문서 ID·프로젝트 / 역할·상태 / 승인자·대체 대상)이 필요합니다. 본문의 표·서신과 항목 별칭은 다양하게 작성할 수 있습니다. 스캔 PDF, OCR, 범용 회사 문서는 지원하지 않습니다.

회사 기밀·실제 고객 문서·개인정보를 업로드하지 마세요.
